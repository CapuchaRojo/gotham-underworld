# M006 — City Economy and Territory Control

Copy `gameplay.py`, `city_economy.py`, and `tests/test_city_economy.py` into the repository, preserving directories. Run `python -m unittest discover -s tests -v`. Launch `python gameplay.py --save career_m006_save.json` and use `districts`, `join 1`, `job courier`, `wait`, `districts`, `events`, `save`, `quit`. Existing save files migrate when loaded; the first economy tick happens on the next day.
